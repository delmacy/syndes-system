# Biblioteca técnica do Syndes

Uma coleção de livros de engenharia, não um painel de features.

> **Editor responsável:** os capítulos refletem os documentos versionados. A presença de uma ficha não comprova implementação integral ou operação homologada.

## Como consultar

Escolha um volume, abra a ficha do módulo e siga os hyperlinks das **oito matérias independentes**. Use as referências para confrontar cada afirmação com o código e o STATUS.

**Nota editorial:** a ficha documenta o estado observado, não promete entrega funcional.
