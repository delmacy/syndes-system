# @syndes/front-shared (internal source package)

One visual component source for `apps/master-admin-web` and `apps/workspace-web`. This package has NO authentication, API client, tenant context, feature routes, permissions, customer data, navigation, secrets or environment access.

Components consolidated from Workspace: `Button`, `Input`, `Badge`, `Card` family and `Separator`. All Workspace usages import directly from `@syndes/front-shared/<component>`. Manager uses the same exported primitives but with `unstyled` for legacy bespoke visual styles; therefore no additional copy of UI logic is maintained. The `unstyled` property only changes default CSS classes; it does not disable keyboard, focus, accessibility, disabled states or security.

This is deliberately a source-first **internal** `file:../../packages/front-shared` dependency, so independently-built Vite apps consume the canonical TypeScript without needing changed CI workflows. Both apps remain separate React builds with their own origins and login boundaries. Before releasing it to GitHub Packages, implement a compiled `dist` build + versioned publishing validation instead of publishing TSX source directly. React, ReactDOM and Base UI are peer dependencies. Vite explicitly deduplicates them to prevent a second React runtime or competing Base UI context. App CSS includes the external source in Tailwind v4 content scanning.

To validate: `cd packages/front-shared && npm ci && npm test`; then `npm ci && npm run build` in each frontend, existing browser regression suites. The source-contract test blocks placing auth, network or tenant-specific logic into this package and prevents cloned component files in the Workspace. Both apps run these tests in their existing `npm test` scripts; the Actions workflow files remain owned by the separate CI task.
