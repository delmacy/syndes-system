# Syndes — linha do tempo do programa

> **Duas perspectivas separadas:** plano futuro e alterações comprovadas. Este é um painel documental, não um cronograma com datas inventadas nem um substituto do GitHub Projects.

## Planejamento e dependências

- [WBS e módulos do programa](../subprojects/README.md): planos e workpackages ligados a cada owner.
- [Cobertura documental dos módulos](README.md#cobertura-real-do-preenchimento-2026-11-12): auditoria parcial com lacunas explícitas.
- [GitHub Issues](https://github.com/delmacy/syndes-system/issues): trabalho registrado; não assumir que cada issue é requisito aprovado.
- [GitHub Projects](https://github.com/users/delmacy/projects): consultar os projetos efetivamente criados; o Syndes Docs **não pressupõe** roadmap com datas ou iterações configuradas.

**Sem datas aprovadas para os workpackages, o portal não desenha Gantt.** As dependências planejadas permanecem nas páginas Evolução e suas WBS. Um compromisso de sprint deve conter responsável, marco e decisão.
