# Monitoramento de engenharia e documentação

Esta página apresenta **informações públicas do GitHub Actions**, consultadas no momento da visualização. Não é um sistema de monitoramento operacional e não substitui testes, evidências de ambiente ou o aceite de produto.

## Como interpretar os indicadores

| Indicador | Significado |
|---|---|
| **CI da main** | Resultado da execução mais recente do pipeline principal |
| **Syndes Docs — Pages** | Build e publicação da documentação |
| **Outros workflows** | Última execução encontrada por nome no histórico recente |
| **Commit da documentação** | Revisão do repositório a partir da qual este site foi gerado |

**Atenção:** um workflow verde não comprova sozinho que todos os módulos estejam integrados, homologados ou operacionais. Uma execução antiga não representa um estado atual de produção.

Os dados são consultados sem credenciais, pois o repositório é público. O GitHub limita chamadas não autenticadas; em caso de indisponibilidade, utilize os links dos workflows. Atualizar o site não muda o estado dos pipelines.
